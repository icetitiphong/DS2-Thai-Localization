# DS2-Thai-Localization
Mod ซับไทย Death Stranding 2

## Skill สำหรับตรวจและเกลาคำแปล

[`thai-game-localization-editor`](skills/thai-game-localization-editor/SKILL.md) ใช้ตรวจบทสนทนา ซับ และคำสั่งจากอังกฤษเป็นไทย โดยรักษาผู้กระทำ เจ้าของ น้ำเสียง และโครงสร้างไฟล์ ไม่เดาผู้พูดจาก UUID

ติดตั้งด้วย skill-installer โดยระบุ repository `icetitiphong/DS2-Thai-Localization` และ path `skills/thai-game-localization-editor` หรือคัดลอกโฟลเดอร์ skill นี้ไปยังโฟลเดอร์ skills ของ Codex

เรียกใช้ด้วย `$thai-game-localization-editor` พร้อมไฟล์ต้นฉบับ คำแปล และขอบเขตที่ต้องการตรวจ Skill ไม่อนุญาตให้ติดตั้ง ZIP หรือเผยแพร่ไฟล์แทนผู้ใช้โดยอัตโนมัติ

หลักทั่วไปอยู่ใน SKILL.md ส่วนคำศัพท์และนโยบายเฉพาะ DS2 อยู่ใน references/ds2-profile.md ไม่ได้รวมไฟล์คำแปล DLL หรือบทเกม และไม่รับรองว่าคำแปลทุกบรรทัดถูกต้อง
